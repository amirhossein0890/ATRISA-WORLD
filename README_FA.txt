پروژه اندروید ATRISA'S WORLD

این پروژه یک پوسته اندرویدی تمام‌صفحه برای بازی فعلی است و فایل APK را از طریق GitHub Actions می‌سازد.

نکته مهم: در این محیط Android SDK/Gradle نصب نیست، بنابراین APK نهایی اینجا کامپایل نشده است.

ساخت APK:
1) محتویات این پروژه را در یک مخزن GitHub قرار دهید.
2) شاخه اصلی مخزن را main نام‌گذاری کنید.
3) به تب Actions بروید و گردش‌کار Build Android APK را اجرا کنید (یا یک commit به main بفرستید).
4) پس از پایان موفق، در بخش Artifacts فایل Atrisa-World-Android-APK را دریافت کنید.
5) فایل app-debug.apk داخل artifact، فایل نصب اندروید است.

بازی برای اجرای Three.js و فونت آنلاین به اینترنت نیاز دارد. این پروژه به‌صورت افقی (landscape) و تمام‌صفحه اجرا می‌شود.
